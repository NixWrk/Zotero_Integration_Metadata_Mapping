# Zotero Web API — itemType × keyPath matrix (RU/EN)

## RU: Источник и метод

Таблица получена **прямым запросом к Zotero Web API**: эндпоинт `/items/new?itemType=<type>` возвращает канонический editable-шаблон для каждого типа. Ключи извлечены скриптом `Zotero_all_items_request.py`, результат сохранён в `zotero_template_keys.json`.

Данные **не зависят от содержимого вашей библиотеки** — это системная схема Zotero.

- Всего itemType: **38**
- Union keyPaths: **133**

## EN: Source and method

Table produced by **direct Zotero Web API queries**: the `/items/new?itemType=<type>` endpoint returns the canonical editable template for each type. Keys extracted by `Zotero_all_items_request.py`, result saved to `zotero_template_keys.json`.

Data is **independent of your library contents** — this is the Zotero system schema.

- Total itemTypes: **38**
- Union keyPaths: **133**

---

## RU: Как читать таблицу

- ✓ — поле присутствует в editable-шаблоне данного `itemType` (гарантировано API).
- пусто — поле отсутствует для данного `itemType`.
- Поля, добавляемые **плагином** (`citekey`, `attachments[].*`, `annotations[].*` и др.), в этой таблице **не отражены** — см. [`plugin_template_variables.md`](plugin_template_variables.md).

## EN: How to read the table

- ✓ — field is present in the editable template for this `itemType` (guaranteed by API).
- empty — field is absent for this `itemType`.
- Fields added by the **plugin** (`citekey`, `attachments[].*`, `annotations[].*`, etc.) are **not in this table** — see [`plugin_template_variables.md`](plugin_template_variables.md).
